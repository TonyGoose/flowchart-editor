# Платформа для контроля навыков составления блок-схем

Интерактивное веб-приложение для проверки знаний алгоритмизации: студенты составляют блок-схемы, преподаватель создаёт задания и видит результаты в реальном времени через Firebase.

---

## Возможности

### Для студента

| Режим | Описание |
|-------|----------|
| **Обучение** | Подсказки включены, таймера нет |
| **Тренировка** | Без подсказок, без таймера |
| **Экзамен** | Таймер + случайный вариант по выбранной теме + проходной балл 70% |

- Перетаскивание блоков из библиотеки на схему (drag & drop)
- Возврат блока в библиотеку при ошибке
- Автоматическая проверка после сдачи: процент, список ошибок, прогресс-бар
- Синхронизация вариантов из облака — кнопка **"Обновить из облака"** загружает только новые/изменённые задания

### Для преподавателя

- Визуальный редактор блок-схем с 8 типами блоков: Start, End, Process, Decision, Data, Predefined Process, Trap, Waypoint
- Два типа стрелок: **Bezier** (плавные) и **Step** (ступенчатые)
- Точки изгиба стрелок (двойной клик на стрелку)
- Авто-разметка схемы (алгоритм dagre)
- Панель свойств блоков и стрелок
- Система ловушек — блоки с неправильными ответами для усложнения задания
- **Публикация вариантов** в Firebase одной кнопкой
- **Просмотр результатов студентов** в реальном времени из любого устройства

### Библиотека заданий

- **55 предустановленных вариантов** по 11 категориям
- Линейные алгоритмы, ветвления, циклы, массивы, сортировка, поиск, математика, численные методы, рекурсия, подпрограммы

## Firebase интеграция

Приложение использует **Firebase Firestore** для синхронизации данных между устройствами преподавателя и студентов.

### Коллекции Firestore

| Коллекция | Назначение | Поля |
|-----------|-----------|------|
| `variants` | Задания (блок-схемы) | все поля варианта + `updatedAt: Timestamp` |
| `results` | Результаты студентов | `studentName`, `groupName`, `variantName`, `score`, `passed`, `date`, `timestamp: Timestamp` |

### Как работает синхронизация вариантов

```
Преподаватель сохраняет вариант
         ↓
publishVariantToCloud() → Firestore variants/{id} с updatedAt = serverTimestamp()
         ↓
Студент нажимает "Обновить из облака"
         ↓
syncNewVariants(lastSyncTime) → WHERE updatedAt > lastSyncTime
         ↓
Только изменённые варианты скачиваются и мерджатся с локальными
lastSyncTime сохраняется в localStorage
```

### Как работает передача результатов

```
Студент сдаёт задание
         ↓
saveResultToCloud() → Firestore results (addDoc с serverTimestamp)
         ↓
Преподаватель входит в админку
         ↓
subscribeToResults() → onSnapshot() — реалтайм-подписка
         ↓
Результаты обновляются автоматически без перезагрузки страницы
```

### Настройка Firebase

#### 1. Создать проект в Firebase Console

1. Перейти на [console.firebase.google.com](https://console.firebase.google.com)
2. Создать новый проект
3. Включить **Firestore Database** (режим Production)
4. В настройках проекта → **Web-приложение** → скопировать конфиг

#### 2. Вставить конфиг в `src/firebase/config.js`

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

#### 3. Правила безопасности Firestore

Firestore Database → Rules:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /variants/{id} {
      allow read: true;
      allow write: true; // Ограничить после подключения Auth
    }
    match /results/{id} {
      allow read, write: true;
    }
  }
}
```

#### 4. Первичная публикация вариантов

После настройки войти в админку → нажать кнопку **"☁ В облако"** — все встроенные варианты загрузятся в Firestore. После этого студенты смогут синхронизировать их через кнопку на главном экране.

## Установка и запуск

### Требования

- Node.js 18+
- npm 9+
- Проект Firebase с включённым Firestore

### Установка

```bash
git clone https://github.com/TonyGoose/flowchart-editor.git
cd flowchart-editor
npm install
```

Вставить Firebase конфиг в `src/firebase/config.js`.

### Запуск

```bash
npm run dev        # Режим разработки → http://localhost:5173
npm run build      # Сборка для продакшена → dist/
npm run preview    # Превью продакшен-сборки
```

## Сценарии использования

### Преподаватель

1. Войти в **Панель управления** (кнопка на главном экране, пароль по умолчанию `admin123`)
2. Вкладка **Варианты** — создавать, редактировать, удалять задания
3. Кнопка **"☁ В облако"** — опубликовать все варианты в Firebase (первичная настройка)
4. При каждом сохранении вариант автоматически обновляется в Firebase
5. Вкладка **Результаты** — видеть результаты всех студентов в реальном времени

### Студент

1. На главном экране нажать **"Обновить из облака"** — получить актуальные варианты
2. Выбрать режим: Обучение / Тренировка / Экзамен
3. Выбрать вариант и составить блок-схему
4. После сдачи результат автоматически отправляется преподавателю
